# KJV Words Milk 45 — Quickstarter

Get value in a few minutes.

---

## 1 minute: Open the report

- Open **`KJV-RD-milk45-COMBINED-REPORT.md`** in the project root.
- Scroll to the compiled content (under “Paste your compiled content below”).
- Skim one source: title → outline → Category 1 verses → Category 2 verses.

---

## 3 minutes: Copy one source to Google Docs

1. In the report, select **one full source** (from “Source Title” through the last verse of Category 2).
2. Copy (Ctrl/Cmd + C).
3. In Google Docs: **File → New → Document**, then paste.
4. Set text color to **black** and **File → Page setup → Page color → white**.

You now have one sermon’s outline and verses in a doc.

---

## 5 minutes: Use it for a devotion or study

1. From the report, pick **Message 1** of any source.
2. Copy: **Source Title** + **Introduction** + **Message 1** + **Category 1 verses** (if Message 1 matches Category 1).
3. Paste into a Doc or note app.
4. Use as a 5–10 minute reading: outline first, then each verse (KJV then Korean/essential message).

---

## 10 minutes: Find a topic

1. In the report, use **Find** (Ctrl/Cmd + F).
2. Search for a word (e.g. “faith”, “복음”, “바울”, “이방인”).
3. Open each hit’s source; read outline and verses.
4. Copy the most relevant source (or one message) into a Doc for later use.

---

## If the report is empty

- Paste your compiled content (from Studio/NotebookLM or another doc) into the “Paste your compiled content below” section of **KJV-RD-milk45-COMBINED-REPORT.md**, or
- Ask the agent to process the YouTube transcripts again and append the results to that file.
