# KJV Words Milk 45 — Tutorial

Step-by-step guide to using the 45 sources: report, outlines, and verses.

---

## Step 1: Open the combined report

1. In the project, open **`KJV-RD-milk45-COMBINED-REPORT.md`**.
2. Confirm that the section **“Paste your compiled content below”** contains the full compiled text (all 40 sources). If it’s empty, paste your compiled content there or ask the agent to regenerate and append.

---

## Step 2: Understand one source

Pick any source (e.g. the first one). You’ll see:

1. **Source Title** — e.g. `[밀크시리즈_1. ...] (박진영)`
2. **I. Full Sermon Outline**
   - Introduction
   - Message 1, Message 2, …
3. **II. All Bible Verses (Categorized by the Two Distinct Messages)**
   - **Category 1** — verses for the first message (KJV + Korean or essential message)
   - **Category 2** — verses for the second message (same format)

Practice: Read the outline, then read Category 1 verses, then Category 2. Notice how the verses support each message.

---

## Step 3: Copy into Google Docs (or another editor)

1. In the report, select the block for one source (or the whole file).
2. Copy (Ctrl/Cmd + C).
3. Open Google Docs and paste (Ctrl/Cmd + V).
4. **Black text on white:** Select all → Text color → black. **File → Page setup → Page color → white.**

You now have an editable document you can share or print.

---

## Step 4: Use by topic

The 45 sources cover themes such as:

- Rightly dividing the Word (Jewish vs Gentile era)
- Paul’s gospel vs other gospels
- Corporate Christ, sin offering, faith
- Spirit, soul, body; Bema Seat; prophecy and fulfillment

In the report, search (Ctrl/Cmd + F) for a topic (e.g. “바울”, “이방인”, “복음”) to jump to relevant sources. Use the outline and verses for that source for study or teaching.

---

## Step 5: Prepare a short study or devotion

1. Choose **one source** and **one message** (e.g. Message 1).
2. Copy from the report: **Source Title** + **Outline (Introduction + that message)** + **Category 1 verses** (if Message 1 = Category 1).
3. Paste into a new Doc. Add a title (e.g. “오늘의 말씀 — [제목]”).
4. Use as a handout or screen share for a 10–15 minute study.

---

## Step 6: Compare KJV and Korean

For any verse in the report:

1. Find the line **KJV:** and the line **Korean:** (or essential message) under it.
2. Read the KJV first, then the Korean.
3. Note differences in emphasis or wording; use the outline to see why the verse is in that category.

This builds familiarity with both languages and with the two-message structure of each source.

---

## Step 7: (Optional) Run the app

When the Next.js app is added to the repo:

1. Terminal: `npm install` then `npm run dev`.
2. Open [http://localhost:3000](http://localhost:3000).
3. Use the UI to browse by topic/category and view verses as designed.

The app will mirror the same content structure as the report.
